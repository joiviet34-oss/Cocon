3. Collecte des données personnelles

Cocon collecte les données suivantes lors de votre utilisation du service :

  • Données de compte : nom, prénom, adresse email (lors de l'inscription)
  • Données de projet : noms des pièces, éléments ajoutés, images uploadées, notes, commentaires

Ces données sont nécessaires au fonctionnement du service et ne sont jamais vendues à des tiers.

4. Finalité du traitement

Les données collectées sont utilisées pour :

  • Permettre la création et la gestion de votre compte
  • Sauvegarder et synchroniser vos projets de décoration
  • Permettre la collaboration entre utilisateurs (partage de projets)
  • Améliorer le service (statistiques anonymisées)

5. Base légale

Le traitement des données repose sur :

  • L'exécution du contrat (article 6.1.b du RGPD) : les données de compte et de projet sont nécessaires pour fournir le service
  • L'intérêt légitime (article 6.1.f du RGPD) : les données techniques pour la sécurité et le bon fonctionnement du service

6. Durée de conservation

  • Données de compte : conservées tant que le compte est actif, supprimées dans les 30 jours suivant la demande de suppression
  • Données de projet : conservées tant que le projet existe, supprimées avec le compte
  • Logs techniques : 30 jours maximum
